# RentaControl 4.2

Aplicación PWA para administración de inmuebles, rentas, cobros, pagos, gastos, depósitos y documentos.

La interfaz se publica mediante GitHub Pages. Los datos privados y documentos permanecen en Supabase protegidos por autenticación y Row Level Security (RLS).

Este repositorio no contiene claves secretas ni `service_role`.
